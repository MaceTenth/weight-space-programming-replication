Below is the middle of a decoder-only transformer language model (a modern Llama-style model): its 30 transformer blocks, without the input layer (token embeddings), without the final norm and without the output layer (unembedding), and without the tokenizer. This is exactly how one block computes (numpy, for one sequence x of shape (n, d), d = 576):

```python
def rms_norm(x, w, eps=1e-05):
    return x / np.sqrt((x * x).mean(-1, keepdims=True) + eps) * w

def block(x, l, W):
    h = rms_norm(x, W[f"ln1_w.{l}"])
    q = h @ W[f"W_q.{l}"].T        # (n, 9*64) : 9 query heads of 64 dims
    k = h @ W[f"W_k.{l}"].T        # (n, 3*64) : 3 key heads; query head j uses key/value head j // 3
    v = h @ W[f"W_v.{l}"].T        # (n, 3*64)
    
    q, k = rope(q), rope(k)        # rotary position embedding, theta = 100000, applied per head over pairs of dims (i, i + 32)
    out = causal_softmax_attention(q, k, v) / sqrt(64) per head, concatenated   # (n, 9*64)
    x = x + out @ W[f"W_o.{l}"].T
    h = rms_norm(x, W[f"ln2_w.{l}"])
    x = x + (silu(h @ W[f"W_gate.{l}"].T) * (h @ W[f"W_up.{l}"].T)) @ W[f"W_down.{l}"].T   # SwiGLU MLP, hidden 1536
    return x
```
